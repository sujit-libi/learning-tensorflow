# Why use machine learning (or deep learning)?

## **Good reason**: Why not?

## **Better reason**: For a complex problem, can you think of all the rules?

"If you can build a **simple rule-based _(maybe not very simple)_** system that doesn't require machine learning, do that" - A wise software engineer... (actually rule 1 of Google's Machine Learning Handbook)

# What deep learning is good for:

1. **Problems with long lists of rules**: when the traditional approach fails, machine learning/deep learning may help.
2. **Continually changing environments**: deep learning can adapt ("learn") to new scenarios
3. **Discovering insights within large collections of data**: can you imagine tring to hand-craft rules for what 101 different kinds of food look like?

# What deep learning is not good for (typically):

1. **When you need explainability**: the patterns learned by a deep learning model are typically uninterpretable by a human.
2. **When the traditional approach is a better option**: if you can accomplish what you neeed with a simple rule-based system.
3. **When errors are unacceptable**: since the outputs of deep learning model aren't always predictable.
4. **When you don't have much data**: deep learning models usually require a fairly large amount of data to produce great results.

# Machine learning vs Deep learning

1. Machine learning for structured data
2. Deep learning for unstructured data
