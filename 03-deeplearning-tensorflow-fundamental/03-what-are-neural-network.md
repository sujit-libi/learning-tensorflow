# What is Neural Network?

- A neural network is a network or circuits of neurons, or in a modern sense , an artificial neural network, composed of artificial neurons or nodes.

#### Components of Neural Network:

- Inputs: Images, Texts, Audio Waves etc.
- Numerical encoding: before data gets used with a neural network, it needs to be turned into numbers
- Learns representation (patterns/features/weights): choose the appropriate neural network for your problem
- Representation Output: Numerical outputs human might not understand fully
- Outputs (a human can understand these): Ramen, Spaghetti, Not a diaster, "Hey Siri, what's the weather today?"

#### Anatomy of Neural Networks

- Input layer: data goes in here - # units/neuron = 2 (Sample)
- Hidden layer(s): learns patterns in data - # units/neurons = 3
- Output layer: outputs learned representation or prediction probabilities

```
Note: "patterns" is an arbitrary term, you'll often hear "embedding", "weights", "feature representation", "feature vectors" all referring to similar things
```

### Types of Learning:
